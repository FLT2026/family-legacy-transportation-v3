# V3.6 Actual Trip Cost — Smoke Test

Run this checklist on the `v3.6-actual-trip-cost` branch.

1. Open `index.html` through a local HTTP server and confirm the browser console has no errors.
2. Confirm the header, footer, navigation, and Test Gate identify V3.6.
3. Select or create a load with a saved V3.5 estimate.
4. Record fuel and toll expenses in Finance and attach at least one receipt.
5. Enter actual total business miles, gallons, average fuel price, and fuel receipt total.
6. If odometer values are used, confirm a mismatched mileage greater than one mile is blocked.
7. Save the actual trip and confirm a V3.6 immutable snapshot is appended to the selected load.
8. Select “No tolls incurred for this trip,” save, confirm the fuel expense, and verify the saved snapshot and checkbox retain the selected toll status.
9. Save the same trip again with unchanged facts and confirm its snapshot ID and MPG-history row are unchanged; reopening or confirming fuel must update the linked expense rather than add a second fuel expense or journal posting.
10. Confirm actual MPG equals actual miles divided by actual gallons.
11. Confirm estimated-versus-actual cost and mileage variances use the selected load only.
12. Confirm the assigned truck is taken from the latest dispatch lock for the selected load.
13. Save another trip for the same truck under a different Load ID and confirm Vehicle MPG History contains both trips.
14. Switch selected loads and confirm no mileage, expense, receipt, variance, or MPG evidence leaks between loads.
15. Confirm the V3.6 gate passes only when mileage, fuel, receipts, tolls/expenses, variance, and MPG history are present.
16. Reload the page and confirm the snapshots and history persist.

Do not merge until all applicable checks pass without browser-console errors.
