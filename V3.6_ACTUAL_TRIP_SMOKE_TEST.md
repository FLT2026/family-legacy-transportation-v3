# V3.6 Actual Trip Cost — Smoke Test

Run this checklist on the `v3.6-actual-trip-cost` branch.

1. Open `index.html` through a local HTTP server and confirm the browser console has no errors.
2. Confirm the header, footer, navigation, and Test Gate identify V3.6.
3. Select or create a load with a saved V3.5 estimate.
4. Record fuel and toll expenses in Finance and attach at least one receipt.
5. Enter actual total business miles, gallons, average fuel price, and fuel receipt total.
6. If odometer values are used, confirm a mismatched mileage greater than one mile is blocked.
7. Save the actual trip and confirm a V3.6 immutable snapshot is appended to the selected load.
8. Confirm actual MPG equals actual miles divided by actual gallons.
9. Confirm estimated-versus-actual cost and mileage variances use the selected load only.
10. Confirm the assigned truck is taken from the latest dispatch lock for the selected load.
11. Save another trip for the same truck and confirm Vehicle MPG History contains both records.
12. Switch selected loads and confirm no mileage, expense, receipt, variance, or MPG evidence leaks between loads.
13. Confirm the V3.6 gate passes only when mileage, fuel, receipts, tolls/expenses, variance, and MPG history are present.
14. Reload the page and confirm the snapshots and history persist.

Do not merge until all applicable checks pass without browser-console errors.
